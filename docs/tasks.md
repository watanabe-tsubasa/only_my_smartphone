# 再生成タスクリスト（現状ベース）

## 現状サマリー
- カメラ起動: `js/camera.js` でアウトカメラを `getUserMedia` で起動し、`<video>` へ貼り付け済み。
- 加速度検知: `js/motion.js` が `devicemotion` を購読し、しきい値超過時に `slash` カスタムイベントを発火。
- UI: `index.html` のボタンで加速度検知の開始／停止を切り替え、ステータス表示を更新。
- 斬撃演出: Canvas レイヤーや効果音は未実装。

## 優先タスク
1. **斬撃エフェクトの描画レイヤー追加**
   - `<canvas>` を video 上に重ねるレイアウトを構築。
   - `slash` イベントを受けて線を描画し、フェードアウトする処理を `js/slash.js` などに分離。
2. **効果音再生（任意だが推奨）**
   - 斬撃発生時に SE を再生できるように Audio 要素を準備。
   - モバイルの自動再生制約を考慮し、ユーザー操作後に初期化。
3. **しきい値と方向判定の調整 UI**
   - 斬撃感度（しきい値）の調整 UI を設置し、`startMotionTracking` に値を渡せるようにする。
   - 角度計算結果をデバッグ表示するオプションを用意して実機調整を容易に。
4. **センサー権限の確実な取得フロー**
   - iOS 向けに `DeviceMotionEvent.requestPermission()` をユーザー操作に紐付けて案内表示。
   - 権限拒否時のリトライ案内を HUD に表示。
5. **エラーハンドリングとフォールバック**
   - カメラ起動失敗やセンサー非対応時にユーザーへ明示するメッセージを追加。
   - 対応していないブラウザの場合の案内（例: デスクトップアクセス時の表示）を用意。
6. **パフォーマンス・後始末**
   - 画面遷移や再読み込み前にカメラストリームを停止する処理を追加。
   - `devicemotion` 監視も停止できるよう、タブ非アクティブ時のリソース管理を検討。
7. **デプロイ準備（Netlify 前提）**
   - 簡易的な `README` に実行／デプロイ手順（ローカル: Live Server, デプロイ: Netlify）の記載を追加。
   - HTTPS が必須である旨を明記し、PC での挙動差異も注記。

## 補足タスク（余力があれば）
- 斬撃方向に応じたビジュアル差分（左右斬りで傾きを変えるなど）の追加。
- フェードアウト中に残像を残すエフェクトや、軽微な画面シェイクの演出。
- 設定値（しきい値など）のローカル保存（`localStorage`）対応。
