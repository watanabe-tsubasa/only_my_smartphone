# Only My Smartphone

ローカルサーバーでそのまま動作するスマートフォン機能デモです。ビルド工程なしで ES Modules を読み込み、カメラ、モーションセンサー、効果音のサンプルをまとめています。

## ディレクトリ構成

```
/
├─ index.html           # メインページ (ES Modules 読み込み)
├─ css/style.css       # 最低限のスタイリング
├─ js/                 # 機能別モジュール
│  ├─ main.js          # 各モジュールの初期化
│  ├─ camera.js        # カメラプレビュー制御
│  ├─ motion.js        # DeviceMotion/DeviceOrientation 読み取り
│  └─ slash.js         # 効果音の再生
├─ assets/slash.mp3    # 任意のスラッシュ音 (差し替え可)
└─ netlify.toml        # ビルド工程なしの Netlify 設定
```

## 使い方 (ローカル開発)

1. リポジトリをクローンし、VS Code などで開きます。
2. VS Code 拡張機能の **Live Server** など、静的ファイルを配信できるローカルサーバーを起動します。
3. `index.html` をブラウザで開くと、各セクションが利用可能です。
   - **カメラ**: 「カメラ開始」でプレビューを開始し、「停止」でストリームを終了します。
   - **モーションセンサー**: iOS ではボタンを押してセンサー利用許可をリクエストします。
   - **スラッシュ効果音**: `assets/slash.mp3` を任意の効果音に差し替えて再生できます。

> カメラやモーションセンサーは HTTPS 環境でのアクセスが推奨されます。

## Netlify へのデプロイ

ビルド工程なしでそのまま配信するため、公開ディレクトリはリポジトリのルート (`/`) に設定します。

### `netlify.toml` を利用する場合

`netlify.toml` を配置済みです。Netlify 側は以下を自動で使用します。

- **Build command**: 空文字 (ビルドなし)
- **Publish directory**: `.`
- すべてのパスを `index.html` にフォールバックするリダイレクト設定

### 管理画面から設定する場合

1. Netlify 管理画面で新規サイト作成 → リポジトリを選択します。
2. **Build command** に空文字 (または未指定) を設定します。
3. **Publish directory** を `.` に設定します。
4. 保存してデプロイします。

以上で、追加のビルド手順なしにデプロイできます。
